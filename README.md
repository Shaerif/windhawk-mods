# WindHawk Mods

Custom Windhawk mods, tested locally before any publishing.

## Mods
- mods/offscreen-window-rescue.wh.cpp: moves installer windows back onto the screen when they open off-screen.

## Install locally
1. Open Windhawk, then Create a new mod.
2. Paste the file contents and compile. Or run: windhawk-cli.exe mod install --file <path>
