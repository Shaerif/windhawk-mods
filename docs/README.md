# Docs

There's one guide per mod. Each one covers install, use, settings, limits and removal.

- [Bulk Copy File and Folder Names](bulk-copy-file-and-folder-names.md): copy the names of the files and folders you select in File Explorer, without their paths, with a hotkey or the right-click menu.
- [Clipboard Hang Watchdog](clipboard-hang-watchdog.md): find the program that holds the clipboard open or blocks it and log it. It starts in log-only mode and can end the program if you turn that on.
- [Focus Follows Mouse](focus-follows-mouse.md): give keyboard focus to the window under the pointer with no click, without bringing it to the front unless you ask.
- [Off-Screen Window Rescue](offscreen-window-rescue.md): move a window back onto the screen when it first opens outside the visible work area.
- [Restart API Logger](restart-api-logger.md): log which Windows API Windows Update calls to restart the PC, and who called it. Version 1 only logs and blocks nothing.
- [Same-App Window Cycler](same-app-window-cycler.md): press Alt+` (the key above Tab on a US keyboard) to cycle through the windows of the app you're using.
- [Title Bar Scroll Roll-Up](titlebar-scroll-rollup.md): scroll the mouse wheel on a title bar to roll the window up to its title bar and back.
- [Window Rules](window-rules.md): give an app a set position, size, monitor, always-on-top flag or opacity each time its window opens.
